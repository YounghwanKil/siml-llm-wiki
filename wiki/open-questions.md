# 확인이 필요한 질문

- 발표 완료일과 채택 연도가 다를 때 제출 양식은 어느 날짜를 기준으로 하나요?
- 동일 연구의 워크숍과 본학회 레코드를 어느 기준으로 중복 제거하나요?
- 공개 SW와 프로그램 저작권 등록을 어떤 증빙으로 연결하나요?
- 공개가 확인된 특허와 권리자 정보를 어디에서 조회하나요?
- 각 과제의 기여율과 실적 인정 범위는 어떤 최신 제출본으로 확정하나요?

항목이 비어 있다고 0건 또는 미실적으로 결론내리지 않습니다. 내부 자료의 구체적인 충돌과 진행 현황은 로컬 private 위키에서 관리합니다.

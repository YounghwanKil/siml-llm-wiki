# 성과 상태와 증빙

논문 채택과 발표, 특허 출원과 등록, 공개 코드와 프로그램 저작권 등록은 서로 다른 사실입니다.

| 항목 | 완료 확인 자료 | 혼동하기 쉬운 자료 |
| --- | --- | --- |
| 특허 출원 | 출원번호와 출원일이 적힌 공식 통지 | 발명신고서·사무소 상담·해외출원 지원 선정 |
| 특허 등록 | 등록번호와 등록일이 적힌 공식 증서 | 국내/국외 출원 완료 통지 |
| SW 저작권 등록 | 등록기관·등록번호·등록일이 적힌 등록증 | 공개 GitHub 저장소·신청서 |
| 논문 발표 | 발표/게재 기록과 양식의 인정 기준 | 채택 예정 표기 |
| 산학협력 과제 | 계약·수행기간·참여내역 | 논문 공동저자 또는 단순 자문 |

예시 행의 숫자와 실제 실적을 구분하고, 미확인 상태를 0건으로 바꾸지 않습니다. 등록일과 증서 발급일도 구분합니다.

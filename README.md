# SIML LLM Wiki

KAIST 이주호 교수님 SIML 연구실의 2024–2026년 공개 연구성과를 연결해 정리하는 LLM 위키입니다. 문서 검색에서 끝내지 않고, 자료를 읽을 때마다 성과·개념·출처 페이지를 갱신합니다. 연구실 공식 홈페이지를 대체하는 공식 행정대장은 아닙니다.

먼저 [위키 색인](wiki/index.md)을 읽으세요. 에이전트는 [AGENTS.md](AGENTS.md)의 ingest, query, lint 절차를 따릅니다.

## 구조

| 경로 | 내용 |
| --- | --- |
| `raw/public/` | 공개 출처에서 확인한 불변 메타데이터와 출처 목록 |
| `wiki/` | LLM이 관리하는 연도별 성과, 논문, 개념, 출처, 종합 정리 |
| `AGENTS.md` | 확인 상태·출처·갱신·질의·공개 규칙 |
| `scripts/lint.py` | 상대 링크, 색인, 메타데이터, 공개 파일 검사 |
| `private/` | 로컬 내부 증빙과 행정 위키. Git 추적·공개 제외 |

## 사용

```text
AGENTS.md와 wiki/index.md를 읽고 새 공개 자료를 ingest해줘.
관련 성과와 개념 페이지를 갱신하고, 충돌을 기록한 뒤 log.md에 남겨줘.
```

```text
2025년과 2026년의 불확실성 연구를 비교해줘.
출처를 붙여 설명하고 결과를 wiki/synthesis/ 아래에 저장해줘.
```

```sh
python3 scripts/lint.py
```

Obsidian에서 이 폴더를 vault로 열 수 있습니다. 상대 Markdown 링크를 사용하므로 GitHub에서도 읽을 수 있습니다. 별도 서버나 임베딩 데이터베이스는 필요하지 않습니다.

## 범위

최초 정리일은 2026년 10월 6일입니다. 연도별 숫자는 공식 홈페이지에 등재된 레코드 수이며 본학회·저널·워크숍을 구분합니다. 동일 연구의 워크숍 발표와 본학회 논문은 서로 다른 레코드일 수 있으므로 행정 제출 건수로 바로 합산하지 않습니다.

등록증·특허 출원서·메일·Slack 원문과 비공개 식별정보는 공개 저장소에 포함하지 않습니다. 공개 코드가 있다는 사실만으로 SW 저작권 등록 또는 사업 실적 귀속을 인정하지 않습니다.
